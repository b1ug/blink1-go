# blink(1) 发现范围

`ListDeviceInfo` 与 `FindDeviceInfoBySerialNumber` 通过现有 GID `FindDevices(0x27b8, 0x01ed)` 请求 blink(1) 的精确 VID/PID 范围，不再先调用全量枚举助手再筛掉其他 HID 设备。公开签名没有变化，也不打开设备句柄。

列表仍按序列号稳定排序，空结果保留 nil slice；按序列号查找仍精确匹配大小写、返回枚举顺序中的首个匹配，未找到时保留原有错误链和文本。查找前完整消费有限枚举通道，使生产者及其清理有机会完成。

过滤在原生后端多早生效取决于所用 GID 版本。本修改不更新依赖 pin；它需要与 GID 对现有 FindDevices 入口的原生过滤修复一起整合。这里的 fake 测试不枚举 USB，也不能证明系统权限弹窗已消失或已定位后台未就绪的唯一原因。原生打开设备的权限与后台生命周期仍须独立验证。
